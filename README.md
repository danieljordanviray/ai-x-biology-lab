# AI x Biology Lab — Daniel Jordan Viray

Interactive, tech-first explanations of AI and machine learning applied to biology.
Built for people who think in math and code: every piece starts from a computing
idea — a scanner, a string search, a supervised learning problem — and shows the
biology it unlocks. Visual first, verifiable always: synthetic data with planted
truths, code you can check, no trust-me statistics.
